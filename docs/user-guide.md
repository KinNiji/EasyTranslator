# EasyTranslator 用户指南

## 开始前

本工具是“逐句辅助口译”，不是连续会议同传。建议在安静环境中，每位发言者完成一句或一小段后再停止录音、核对文本并翻译。

首次打开页面必须阅读并确认使用说明。对话记录保存在这台设备、这个浏览器的本地存储中；清理网站数据或更换浏览器前，请先导出 JSON 备份。

## 配置 API

打开右上角的设置按钮，填写：

- **Base URL**：兼容 OpenAI 的地址，CloseAI 默认为 `https://api.openai-proxy.org/v1`。
- **API Key**：只在当前页面会话中存在，刷新后自动清除。
- **STT / Translation / TTS**：可根据服务商实际支持的模型名称调整。
- **本地计费估算**：只影响本页面的费用估算，不会改变服务商账单。

点击“测试 API”会验证最小翻译请求。若出现认证、余额、限流、模型或 CORS 错误，请根据页面提示更新设置后重试。

## 记录与翻译一条发言

1. 新建或选择一个对话。
2. 填写发言者，点击“开始录音”或直接输入原文。
3. 录音时，页面约每 4 秒会追加一次转写预览；停止后请校对文本。
4. 从下拉框选择来源语言；无法确认时可保留“待确认”。
5. 点击“识别并翻译”。系统会识别语言并展示中文、法语、英语文本。
6. 点击任一语言的“发音”即可请求并播放该语言语音。

当原文被修改，现有译文会标为“待重译”。确认并翻译后，来源语言的原文不会被模型静默替换；手动修改的译文也会保留，直到再次明确翻译。

## 浏览与导出

- 只有当前发言已完成识别与翻译时，才可新建下一句。
- 在“导出”菜单中选择 Markdown、Word 或 PDF，以及原文、中文、法语、英语版本。
- Word 为可编辑 `.docx`；PDF 为优先保证中、法、英显示的页面图像，不保证正文可选中。
- JSON 备份会保留发言、译文和用量明细。导入时会生成新的本地 ID，不会导入 API Key、音频或页面设置。

## 现场建议

- 避免一次录入太长的发言；短句更快、更容易校对。
- 对日期、药名、数字、缩写和人名进行人工确认。
- 网络不稳定时优先用文字输入；已输入的文本会继续保留在当前对话中。
- 如果需要清空设备数据，请先导出 JSON；删除对话会删除该浏览器里的对应记录。
